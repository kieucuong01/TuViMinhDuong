# Xem Tử vi 2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one complete, personalized “Xem Tử vi 2026” journey from indexable landing page to evidence-backed annual chart reading.

**Architecture:** Add a pure deterministic annual-reading engine over the existing `TuViChart`, render it as a server component inside the existing chart page, and add one allowlisted chart-form experience that locks `viewYear` to 2026. Keep the only new indexable surface at `/xem-tu-vi-2026`; personal result URLs remain noindex.

**Tech Stack:** Next.js 16 App Router, React 19 server/client components, TypeScript, Vitest, Tailwind/global CSS, existing Prisma chart persistence and JSON-LD helpers.

## Global Constraints

- Public Vietnamese copy must be clear for adults 30–60, conversational, and free from technical jargon.
- Do not change the chart engine or payment gates.
- Do not diagnose disease or guarantee financial, marriage, career, or fate outcomes.
- Create one indexable route only; do not generate age/gender doorway pages.
- Keep personal chart results private and `noindex`.
- Use existing semantic colors/components, 44px or larger touch targets, visible focus states, responsive layouts, and no emoji icons.
- Every production behavior must be preceded by a failing test.
