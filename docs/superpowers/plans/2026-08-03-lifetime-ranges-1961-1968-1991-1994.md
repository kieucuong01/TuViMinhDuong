# Lifetime Ranges 1961–1968 and 1991–1994 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish complete male and female lifetime Tu vi articles for 1961–1968 and 1991–1994 with production-ready covers, indexing and live verification.

**Architecture:** Extend the existing `adultExpansionRows` structured source and keep `buildArticle()` as the single generator for article, card and sibling-link data. Existing consumers continue to provide seed content, static params, canonical routes and sitemap entries without new routing code.

**Tech Stack:** Next.js 16, React 19, TypeScript, Vitest, built-in image generator, WebP, PM2/Nginx VPS release script.

## Global Constraints

- Work only in the isolated branch `codex/lifetime-ranges-1961-1968-1991-1994`.
- Publish exactly 12 years and both genders, producing 24 distinct slugs and 24 local WebP covers.
- Keep canonical URLs under `/xem-tu-vi-tron-doi/<slug>` and preserve existing UI, payment, auth and chart behavior.
- Use content date `2026-08-03`; the hub and sitemap must derive their update date from shared data.
- Every cover must be 1200×675 WebP, below 260 KB, without text, logo or watermark.
- Use Node 24 for all Next.js, Vitest and npm lifecycle commands.
